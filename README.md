# tg.greek-trainer

Telegram-бот, который учит греческие слова по алгоритму интервального повторения FSRS.
Словарь один на всех, прогресс у каждого ученика свой: бот запоминает, какие слова знаете вы,
а какие ваш друг, по Telegram-аккаунту.

## Как проходит занятие

Отправьте `/review`. Бот покажет карточку, дождётся ответа и спросит, насколько легко было
вспомнить: «Забыл», «Трудно», «Хорошо» или «Легко». На кнопках сразу видно, через сколько
карточка вернётся при каждом ответе. Когда карточки на сейчас закончатся, бот назовёт время
следующего повторения.

На каждое слово бот заводит три вида карточек:

- **Узнавание.** Греческое слово с озвучкой, вы вспоминаете перевод и нажимаете «Показать ответ».
- **Вспоминание.** Русский перевод, вы печатаете слово по-гречески. Бот сверяет ответ и отдельно
  предупреждает, если ошибка только в ударении.
- **Пропуск в предложении.** Ваш пример с дыркой на месте слова, вы вписываете нужную форму.

Карточки одного слова не попадаются в один день. Иначе узнавание утром подсказывало бы ответ на
вспоминание вечером. День у бота начинается в 04:00, так что занятие за полночь идёт в счёт того
дня, в который вы его начали.

FSRS хранит для каждой карточки стабильность и сложность памяти и назначает повтор в момент,
когда вероятность вспомнить падает до 90 %. Это тот же алгоритм, что в Anki с версии 23.10.
Каждый ответ бот записывает в историю, по ней потом можно подобрать параметры FSRS под себя.

Озвучка идёт через бесплатные нейроголоса Microsoft Edge, по умолчанию `el-GR-AthinaNeural`.
Каждую фразу бот синтезирует один раз и дальше отправляет по `file_id`.

## Команды

| Команда | Что делает |
|---|---|
| `/review` | Повторение |
| `/check` | Быстро отметить слова, которые вы уже знаете |
| `/add` | Добавить слово |
| `/stats` | Сколько слов, карточек, ответов сегодня и процент запоминания за 30 дней |
| `/settings` | Лимит новых карточек в день и время напоминания |
| `/help` | Формат `/add` |

Раз в день в заданное время бот присылает напоминание, если есть что повторить.
Изменить время или отключить: `/settings 19:30`, `/settings off`.

## Если часть слов вы уже знаете

Отправьте `/check`. Бот покажет слова, которые вы ещё не повторяли, по одному с переводом, без
дневного лимита. «Знаю» ставит всем карточкам слова оценку «Легко»: они вернутся примерно через
неделю как контрольный вопрос, а дальше уйдут на месяцы. Если на контроле вы слово не вспомните,
оно пойдёт в обычное обучение. «Учить» оставляет слово новым, «Хватит» прерывает проход,
следующий `/check` продолжит с того же места.

## Сколько новых слов в день

Каждая новая карточка тянет за собой 5–8 повторений в первый месяц, поэтому бот вводит новые
карточки порциями: по умолчанию 20 в день. Поменять: `/settings 30`. Слова, отмеченные через
`/check`, в лимит не входят.

## Как добавить слово

Отправьте `/add`, затем блок текста:

```
ξέρω
знать; уметь
ξέρω να + глагол = уметь
Δεν *ξέρω* πού είναι η στάση. | Я не знаю, где остановка.
```

Первая строка слово, вторая перевод. Строка с `|` становится примером, а форма в звёздочках
внутри примера превращается в карточку «пропуск в предложении». Остальные строки бот сохраняет
как заметку и показывает вместе с ответом.

Слово попадает в общий словарь, и каждый ученик получает по нему свои карточки. Бот считает
`ξερω` и `Ξέρω` одним словом, поэтому дубликаты с другим регистром или без ударения отклоняет.

Много слов за раз: положите блоки в файл через пустую строку и запустите
`python -m greek_trainer.seed seeds/*.txt`. Слова, которые уже есть, бот пропустит. Файлы
лежат в `seeds/`.

## Запуск

Нужны Python 3.12, [uv](https://docs.astral.sh/uv/) и Docker.

```bash
cp .env.example .env              # вписать BOT_TOKEN и ALLOWED_TELEGRAM_IDS
docker compose up -d              # Postgres 16 на 127.0.0.1:5447
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python --require-hashes -r requirements-dev.lock
uv pip install --python .venv/bin/python --no-deps -e .
.venv/bin/alembic upgrade head
.venv/bin/python -m greek_trainer.seed seeds/a1.txt
.venv/bin/python -m greek_trainer
```

Токен выдаёт [@BotFather](https://t.me/BotFather), свой числовой id подскажет
[@userinfobot](https://t.me/userinfobot). Бот отвечает только тем, чьи id перечислены в
`ALLOWED_TELEGRAM_IDS`, остальных игнорирует без ответа.

### Настройки

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BOT_TOKEN` | | Токен бота |
| `ALLOWED_TELEGRAM_IDS` | | Id учеников через запятую |
| `DATABASE_URL` | локальный Postgres | Строка подключения `postgresql+asyncpg://…` |
| `TIMEZONE` | `Europe/Nicosia` | Часовой пояс для напоминаний и границы дня |
| `REMINDER_TIME` | `19:00` | Время напоминания |
| `DAILY_NEW_CARDS` | `20` | Сколько новых карточек бот вводит в день |
| `DESIRED_RETENTION` | `0.9` | Целевая вероятность вспомнить |
| `TTS_VOICE` | `el-GR-AthinaNeural` | Голос озвучки |

Значения из `.env` применяются к новым ученикам при первом сообщении; дальше каждый меняет
свои через `/settings`.

### В Docker

`Dockerfile` собирает образ, который при старте накатывает миграции и запускает бота. Ему нужны
те же переменные окружения и внешний Postgres. Перед запуском бота контейнер прогоняет seed по
всем файлам в `seeds/`, поэтому новые слова достаточно добавить в файл и запушить.

## Разработка

```bash
.venv/bin/python -m pytest -q                      # тесты ходят в greek_trainer_test
.venv/bin/ruff format --check . && .venv/bin/ruff check . && .venv/bin/mypy
```

Схему меняйте только через Alembic: `alembic revision --autogenerate -m "..."`, потом проверьте
файл руками. Зависимости пишите в `requirements*.txt`, а `*.lock` пересобирайте командой
`uv pip compile requirements.txt --generate-hashes --python-version 3.12 -o requirements.lock`.
